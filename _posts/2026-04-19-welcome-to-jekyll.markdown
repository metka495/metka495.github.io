你好！欢迎来到我的个人技术博客。

你会在 `_posts` 目录中找到这篇文章。去编辑它并重新构建网站，就能看到你的更改。你可以通过多种方式重新构建网站，最常用的方式是运行 `jekyll serve`，这会启动一个 Web 服务器，并在文件更新时自动重新生成网站。

## Jekyll 博客文章格式

Jekyll 要求博客文章文件按照以下格式命名：

`YEAR-MONTH-DAY-title.MARKUP`

其中 `YEAR` 是四位数字，`MONTH` 和 `DAY` 都是两位数字，`MARKUP` 是表示文件中使用的格式的文件扩展名。之后，包含必要的前置元数据。看看这篇文章的源代码，了解它的工作原理。

## 代码高亮示例

Jekyll 还提供强大的代码片段支持：

```python
def hello_world():
    print("Hello, World!")
    return True

hello_world()
```

```javascript
function greet(name) {
    console.log(`Hello, ${name}!`);
}

greet('Developer');
```

```bash
# 示例 shell 命令
echo "Hello from shell!"
ls -la
git status
```
